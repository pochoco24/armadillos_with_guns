## A work-in-progress demo game

This is a prototype project made to demonstrate some of my gamedev knowledge. Since it mostly serves as a portfolio project, the pace of development is unhurried.
All of the planning is done in a Miro whiteboard. The models and textures in `external_workfiles` are made by me.

## Current Controls:
- Walk: WASD
- Jump: Space
- Roll Into Ball: Shift
